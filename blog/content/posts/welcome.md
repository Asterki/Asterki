## Hello there!

Welcome to my personal blog. This is where I'll be sharing thoughts, notes, and things I learn along the way.

### What to expect

- **Project deep-dives** — the stories behind the code
- **Learning notes** — things I pick up as I go
- **Tech experiments** — prototypes, side quests, and curious ideas

### About me

I'm Fernando Rivera — a developer, workshop instructor, and community builder from Comayagua, Honduras. I build internal tools at UNAH Campus Comayagua, organize tech events as a Microsoft Learn Student Ambassador, and study Computer Systems Engineering.

### Tech stack of this blog

This blog is built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme. It's part of my main website, which is built with React + Vite + TypeScript + Tailwind CSS.
